## Variables para usar

Autor: Richard Favio Asturimac Medina 

Es necesario usar estas variables, según Chat GPT Modelo Luna estas variables son las ideales para la creación del Pipeline

- banda_riesgo 
- numero_productos 
- activo_movil 
- tiene_tarjeta_credito
- dias_ultima_transaccion 
- antiguedad_direccion_meses
- visitas_web 
- distancia_sucursal_km 
- dia_preferido_pago 

Nota: Es necesario hacer los análisis usando meses iniciales y un mes final como objetivo (target)
